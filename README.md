## Featured Technical Project

### Creating Images with Diffusion Models

This midterm project explored the implementation, training, and evaluation of a class-conditioned diffusion model using the Fashion-MNIST dataset.

**Experimental results:**

- 48,000 training images
- 12,000 validation images
- 30 training epochs
- 300 diffusion steps
- U-Net neural network architecture
- Training loss decreased from 0.1160 to 0.0713
- Lowest validation loss: 0.07147
- CLIP image-text similarity evaluation

This project strengthened my understanding of generative AI, image generation, neural network training, and model evaluation. It also demonstrated that improvements in training loss do not necessarily guarantee accurate or realistic generated images.
