## Featured Technical Project

### Creating Images with Diffusion Models

This midterm project explored the implementation, training, and evaluation of a class-conditioned diffusion model using the Fashion-MNIST dataset.

### Experimental Results

| Performance Metric | Result |
|---|---:|
| Training Images | 48,000 |
| Validation Images | 12,000 |
| Training Epochs | 30 |
| Diffusion Steps | 300 |
| Initial Training Loss | 0.1160 |
| Final Training Loss | 0.0713 |
| Training Loss Reduction | Approximately 38.5% |
| Lowest Validation Loss | 0.07147 |
| Best Model Checkpoint | Epoch 29 |
| Average CLIP Similarity | 0.2812 |

This project strengthened my understanding of generative AI, image generation, neural network training, and model evaluation.

It also demonstrated that improvements in training loss do not necessarily guarantee accurate or realistic generated images.
