# A03 | The Neural Network Zoo

### Meet the CNN Cheetah

## Assignment Overview

The Neural Network Zoo is a creative educational project that explores different neural network architectures by comparing their unique characteristics to animals.

My selected architecture was the Convolutional Neural Network (CNN), represented by a cheetah because of its ability to recognize visual details.

The project combines technical research, visual storytelling, and simplified explanations to make deep learning concepts more accessible.

## Learning Objectives

- Understand the fundamental structure of neural networks.
- Explore how convolutional neural networks process images.
- Compare different neural network architectures.
- Understand feature extraction and pattern recognition.
- Identify practical applications of computer vision.

## Neural Network Architectures

| Architecture | Animal Representation | Primary Strength |
|---|---|---|
| CNN | Cheetah | Visual pattern recognition |
| RNN | Raccoon | Sequential information processing |
| LSTM | Lemur | Learning longer-term dependencies |
| Transformer | Owl | Attention and contextual relationships |

## Key Concepts

- Artificial neurons
- Input, hidden, and output layers
- Convolutional layers
- Filters and feature maps
- Pooling and downsampling
- Shared weights
- Hierarchical feature extraction
- Image classification

## How a CNN Works

1. Receives an image represented by numerical pixel values.
2. Applies learned filters to identify visual features.
3. Reduces feature-map dimensions where appropriate.
4. Combines learned features to generate predictions.
5. Adjusts model weights during training to reduce prediction errors.

## Real-World Applications

- Image recognition
- Medical image analysis
- Manufacturing quality control
- Object detection
- Computer vision systems

## Personal Learning Reflection

This assignment helped me understand that neural networks have different architectures designed to solve different types of problems.

I learned that convolutional neural networks are particularly effective at recognizing visual patterns because they can identify smaller features and combine them into increasingly complex representations.

Comparing CNNs with RNNs, LSTMs, and Transformers also helped me recognize the importance of selecting an architecture based on the type of data and the intended application.

The creative approach used in this assignment strengthened my ability to communicate complex artificial intelligence concepts through visual storytelling and simplified explanations.
