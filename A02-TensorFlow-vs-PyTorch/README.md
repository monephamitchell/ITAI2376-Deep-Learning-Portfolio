# A02 | TensorFlow vs. PyTorch

## Assignment Overview

This assignment explores two widely used deep learning frameworks, TensorFlow and PyTorch. The objective was to compare their features, development workflows, advantages, limitations, and real-world applications.

## Learning Objectives

- Understand the differences between TensorFlow and PyTorch.
- Explore neural network development.
- Compare model training and evaluation workflows.
- Identify real-world applications of both frameworks.
- Understand how to select an appropriate framework.

## Key Concepts

- TensorFlow and Keras
- PyTorch and Autograd
- Neural network development
- Model training and evaluation
- Loss functions and optimizers
- Model deployment and scalability

## Assignment Deliverables

- Comparative research report
- PowerPoint presentation
- Jupyter Notebook demonstration

## Technologies Used

- Python
- TensorFlow
- Keras
- PyTorch
- Jupyter Notebook

## Personal Learning Reflection

This assignment helped me understand that TensorFlow and PyTorch are both powerful deep learning frameworks, but they offer different approaches to developing artificial intelligence models.

I learned that PyTorch provides flexibility and control over the training process, while TensorFlow offers convenient tools for model development and deployment through its broader ecosystem.

The practical demonstration helped connect theoretical concepts with programming and model training. I also learned that neither framework is automatically better than the other, as the appropriate choice depends on the project's requirements, resources, and objectives.
