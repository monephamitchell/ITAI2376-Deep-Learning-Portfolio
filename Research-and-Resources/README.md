# Research and Learning Resources

## ITAI 2376 | Deep Learning

This section documents educational resources, research publications, technical documentation, and industry applications relevant to my deep learning studies.

These resources support my understanding of artificial intelligence concepts, practical implementation, model evaluation, and real-world applications.

## 1. Deep Learning Frameworks

### TensorFlow

[Official TensorFlow Documentation](https://www.tensorflow.org/)

Explains the tools and techniques used to develop, train, and deploy machine learning and deep learning models.

Relevance: Supports my understanding of neural network development, Keras, and model deployment.

### PyTorch

[Official PyTorch Documentation](https://pytorch.org/docs/stable/)

Provides technical documentation for tensor operations, automatic differentiation, neural network development, and model training.

Relevance: Supports practical experimentation and the implementation of deep learning models.

## 2. Neural Networks and Computer Vision

### Stanford CS231n

[Deep Learning for Computer Vision](https://cs231n.github.io/)

Provides educational material covering convolutional neural networks, image classification, feature extraction, and neural network training.

Relevance: Supports my Neural Network Zoo assignment and understanding of CNN architectures.

### Deep Learning Book

[Deep Learning - Goodfellow, Bengio, and Courville](https://www.deeplearningbook.org/)

A comprehensive academic resource covering the mathematical foundations and architectures used in deep learning.

Relevance: Provides theoretical support for understanding neural networks, optimization, and generative models.

## 3. Model Optimization

### Google Machine Learning Crash Course

[Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)

Explains foundational machine learning concepts, model training, loss functions, and evaluation.

Relevance: Supports my understanding of gradient descent, learning rates, and model optimization.

### IBM - Gradient Descent

[What Is Gradient Descent?](https://www.ibm.com/think/topics/gradient-descent)

Explains how optimization algorithms adjust model parameters to minimize loss.

Relevance: Supports my educational project, The Little Robot and the Learning Hill.

## 4. Generative Artificial Intelligence

### Variational Autoencoders

Kingma, D. P., and Welling, M. (2013).

[Auto-Encoding Variational Bayes](https://arxiv.org/abs/1312.6114)

Introduces the foundations of variational autoencoders and probabilistic latent representations.

Relevance: Extends my understanding of how generative models represent data and generate new samples.

### Generative Adversarial Networks

Goodfellow et al. (2014).

[Generative Adversarial Nets](https://arxiv.org/abs/1406.2661)

Introduces an adversarial learning approach involving a generator and discriminator.

Relevance: Provides a foundation for understanding how competing neural networks can support generative learning.

### Diffusion Models

Ho, J., Jain, A., and Abbeel, P. (2020).

[Denoising Diffusion Probabilistic Models](https://arxiv.org/abs/2006.11239)

Explores image generation through progressive noise addition and learned reverse diffusion.

Relevance: Provides theoretical support for my diffusion model midterm project.

## 5. Datasets and Model Evaluation

### Fashion-MNIST

Xiao, H., Rasul, K., and Vollgraf, R. (2017).

[Fashion-MNIST Dataset](https://arxiv.org/abs/1708.07747)

Introduces a dataset of grayscale clothing images designed for machine learning experimentation.

Relevance: This dataset was used to train and evaluate my class-conditioned diffusion model.

### CLIP

Radford et al. (2021).

[Learning Transferable Visual Models From Natural Language Supervision](https://proceedings.mlr.press/v139/radford21a.html)

Explores the relationship between images and natural language through learned representations.

Relevance: Supported the optional image-text similarity evaluation completed during my diffusion model midterm.

My experiment also demonstrated that automated similarity scores should be interpreted alongside human evaluation.

## 6. Natural Language Processing

### Speech and Language Processing

Jurafsky, D., and Martin, J. H.

[Speech and Language Processing](https://web.stanford.edu/~jurafsky/slp3/)

Covers language modeling, contextual representations, machine translation, Transformers, and other NLP concepts.

Relevance: Supports my analysis of Arrival and the challenges associated with language interpretation, ambiguity, and contextual understanding.

## 7. Reinforcement Learning and Intelligent Agents

### Reinforcement Learning: An Introduction

Sutton, R. S., and Barto, A. G.

[Reinforcement Learning Textbook](http://incompleteideas.net/book/the-book-2nd.html)

Explores agents, environments, rewards, policies, and learning through interaction.

Relevance: Provides additional theoretical support for understanding reinforcement learning and goal-oriented agents.

Relevance: Demonstrates how deep learning frameworks can address practical industry challenges.

### LinkedIn and PyTorch

[LinkedIn - Extreme-Scale Optimization](https://pytorch.org/blog/how-linkedin-uses-pytorch-to-solve-extreme-scale-optimization-problems/)

Relevance: Demonstrates the use of deep learning frameworks and accelerated computation beyond traditional image classification.
